# Portfólio TDS 2025.08.52

Portfólio coletivo dos estudantes do curso Técnico em Desenvolvimento de Sistemas do SENAC — Centro de Educação Profissional Jó Rufino e Carlos Aguiar, em Taguatinga/DF. A página reúne projetos desenvolvidos pela turma e apresenta suas tecnologias e competências.

## Conteúdo

- Apresentação da turma e do portfólio.
- Vitrine com 10 projetos, com links para as aplicações e seus repositórios.
- Filtros de projetos por categoria.
- Seções sobre a turma e as tecnologias trabalhadas.
- Navegação responsiva para dispositivos móveis.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Imagens locais

O site é estático e não requer backend, dependências ou processo de build.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.

Para editar o projeto, abra a pasta no VS Code e altere o HTML, os estilos ou o JavaScript incorporados em `index.html`.

## Estrutura

```text
.
├── index.html
├── README.md
└── img/
    ├── Senac_logo.svg.webp
    └── logo.jpeg
```

A página utiliza `img/Senac_logo.svg.webp` no cabeçalho e `img/logo.jpeg` como imagem de compartilhamento nas metatags sociais. Mantenha esses arquivos nos mesmos caminhos relativos para que a marca e a prévia do link continuem carregando.

## Publicação

Por ser um site estático, pode ser publicado em serviços como GitHub Pages ou Vercel. Publique a pasta raiz do projeto, mantendo `index.html` e a pasta `img/` juntos.

## Observações

- Os links dos projetos levam a sites externos e a repositórios GitHub.
- As tecnologias listadas representam competências trabalhadas pela turma; a stack pode variar entre os projetos.
- O ano exibido no rodapé é preenchido automaticamente pelo navegador.
